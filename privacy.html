Privacy policy

Gabriel backup is a personal backup tool operated by its owner. This policy describes its Google Drive backup storage.

Google Drive access

The owner grants rclone access to Google Drive. The configured Drive permission permits access to files across that account. Backup operations list, read, create, and delete repository files as needed for storage, restore, and retention.

Data storage

Restic encrypts backup contents before rclone uploads them to the owner's Google Drive. Google stores the encrypted repository objects and can see storage metadata such as object names and sizes.

OAuth credentials are stored on the owner's server and used by rclone to access Google Drive.

Retention and removal

The owner's backup settings control retention. The owner can revoke this application's access in Google Account settings. Revoking access does not delete backups already stored in Google Drive; the owner can remove those separately.
